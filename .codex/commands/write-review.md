## ★ 말투 다양성 (가장 중요)

### 금지: 동일 패턴 반복
리뷰 간에 같은 말투/종결어미/이음새가 반복되면 봇이 쓴 티가 남. 매 리뷰마다 아래 풀에서 **다른 조합**을 선택해야 함.

### 종결어미 풀 (매 리뷰마다 주로 쓰는 어미를 바꿔야 함)

| 패턴 | 예시 | 어울리는 페르소나 |
|------|------|-------------------|
| ~요 체 | "좋아요", "먹고 있어요" | 30~40대 여성 |
| ~입니다 체 | "만족합니다", "추천드립니다" | 40~60대 남성, 격식체 |
| ~거든요 | "원래 잘 못 먹거든요" | 설명형 화자 |
| ~더라고요 | "진하더라고요" | 경험 서술형 |
| ~네요 | "다르네요", "좋네요" | 감탄/발견형 |
| ~죠 | "편한 거 있죠", "당연하죠" | 동의 유도형 |
| ~ㅎㅎ/ㅋㅋ 마무리 | "효과 있는 것 같아요 ㅎㅎ" | 캐주얼 |
| ~.. 여운형 | "잘 먹고 있습니다.." | 조용한 만족 |
| 단정형 | "이거로 정착했어요", "끊을 생각 없어요" | 확신 있는 화자 |
| 의문형 마무리 | "최고의 후기 아닐까요" | 수사적 질문 |

### 이음새(전환어) 풀 — 동일 이음새 2개 리뷰 연속 금지

| 이음새 | 용도 |
|--------|------|
| ~거든요 | 이유 설명 |
| ~잖아요 | 공감 유도 |
| ~니까요 / ~니까 | 인과 |
| ~어서요 / ~이라서 | 원인 |
| ~인 게 | 설명 도입 |
| ~하면서 / ~하다가 | 시간순 |
| 근데 / 그런데 | 전환 |
| 그래서 / 그러다 | 결과 |
| 솔직히 / 사실 | 고백 |
| 한편 / 아무튼 | 화제 전환 |

**규칙**: 한 리뷰 안에서 `~거든요`를 3회 이상 쓰지 않는다. `~더라고요`도 마찬가지.

### 끝맺음 풀 — 절대 겹치지 않게

아래에서 매 리뷰마다 **다른 끝맺음**을 사용. 인접 리뷰와 같은 끝맺음 금지.

| 유형 | 예시 |
|------|------|
| 정착 선언 | "이걸로 완전 정착했어요", "다른 데는 안 봐요" |
| 재구매 의지 | "세 번째 박스 주문 갑니다", "벌써 다음 거 장바구니에 담았어요" |
| 추천 | "한번 드셔보세요", "후회 안 하실 거예요" |
| 감사 | "감사하게 잘 먹고 있습니다", "좋은 거 알게 돼서 고마워요" |
| 습관 | "이제 안 먹으면 허전해요", "아침 루틴이 됐어요" |
| 기대 | "한 달 후에 다시 후기 올릴게요", "효과 더 보면 재주문할게요" |
| 확신 | "끊을 생각이 전혀 없어요", "건강원 돌아갈 생각 없습니다" |
| 보고형 | "효과는 확실히 체감했습니다..", "결과적으로 잘 골랐네요" |
| 여운 | "잘 먹고 있어요...", "딸 덕에 좋은 거 알게 됐네" |
| 질문형 | "최고의 후기 아닐까요", "이만한 게 또 있을까요" |
| 짧은 단정 | "만족이에요!", "급 다릅니다" |

### 맛/품질 묘사 풀 — "잡내 없이 담백하게" 남발 금지

같은 표현을 2개 리뷰 연속 사용 금지. 아래에서 골고루 분산:

| 표현 | 뉘앙스 |
|------|--------|
| 잡내 없이 담백하게 | 기본형 |
| 비린 맛 없이 깔끔하게 | 비린내 강조 |
| 역한 향 없이 부드럽게 | 향 강조 |
| 뒷맛이 깨끗해서 | 뒷맛 강조 |
| 구수하면서 부드러운 | 맛 긍정 |
| 비릿한 맛이 전혀 없고 | 단정형 |
| 냄새가 거의 안 나서 | 후각 강조 |
| 한약 느낌인데 먹을 만한 | 한약 비유 |
| 쌉쌀한데 넘어가는 | 복합맛 |

### 포장 묘사 풀 — "개별 포장이라 하나씩 꺼내 먹기 편하고" 남발 금지

| 표현 |
|------|
| 낱개 포장이라 간편해요 |
| 한 포씩 나눠져 있어서 |
| 하나씩 포장돼 있어 |
| 파우치 하나씩 꺼내면 되니까 |
| 낱개라 위생적이고 |
| 포장이 깔끔하게 나눠져 있어서 |

## ★ 줄바꿈 패턴 다양성

줄바꿈은 리뷰의 "숨결"을 결정함. 모든 리뷰가 같은 패턴이면 부자연스러움.

### 줄바꿈 패턴 유형

| 패턴 | 설명 | 적용 |
|------|------|------|
| A. 줄글 | 줄바꿈 없이 한 덩어리 | 40대 남성, 빠르게 쓰는 사람 |
| B. 2~3단락 | 도입-본론-마무리 구분 | 30~40대 여성, 정돈된 글 |
| C. 빈줄 단락 | 빈 줄(\n\n)로 큰 단락 구분 | 장문 리뷰, 스토리형 |
| D. 매문장 줄바꿈 | 거의 매 문장 끝에 \n | 60~70대, 카톡 치듯 쓰는 분 |
| E. 혼합형 | 앞부분 줄글 + 중간부터 줄바꿈 | 감정 고조될 때 줄바꿈 시작 |

### 적용 규칙

- **상세 리뷰 (1~19 같은 긴 글)**: A, B, C, D, E 모두 사용 가능. 인접 리뷰끼리 같은 패턴 금지
- **중간 리뷰**: A(40%), B(40%), 나머지(20%) 비율로 분산
- **간단 리뷰**: 대부분 줄바꿈 없음. 5개 중 1개 정도만 \n 포함 (2문장을 나눌 때)

### 줄바꿈 예시

```
# 패턴 A (줄글) — 40대 남성
아내가 주문해줬어요... 저는 흑염소 진액이라는 게 뭔지도 잘 몰랐고, 한약 같은 거 잘 못 먹는 편이라 솔직히 반기지 않았습니다. 냄새 나는 거 아닌가, 쓰고 먹기 힘든 거 아닌가 걱정했거든요. 박스 받아놓고 이틀 정도 안 뜯고 있었어요. 아내가 자꾸 먹으라고 해서 마지못해 하나 뜯었는데 생각이 바뀌었습니다.

# 패턴 B (2~3단락) — 30대 여성
둘째 낳고 나서 시어머니가 보내주셨어요. 솔직히 처음엔 좀 부담스러웠거든요, 흑염소가 뭔지도 잘 모르겠고.
그냥 박스 채로 쌓아두다가 한 달쯤 지나서 슬슬 먹기 시작했어요 산후에 몸이 너무 안 좋아서요.
두 달쯤 꾸준히 먹고 나니까 이전보다 손발이 덜 차가운 느낌이 들기 시작했어요.

# 패턴 D (매문장 줄바꿈) — 70대 여성
딸이 보내준 거예요.
제가 요즘 기운이 없다고 했더니 인터넷으로 이걸 주문해서 보내줬더라고요.
박스가 오길래 뭔가 했어요 기특하기도 하지.
열어봤더니 포장이 깔끔하게 돼 있고 하나씩 낱개로 다 포장이 돼 있더라고요.
```

## 페르소나 구성

- 성별: 남/여 적절히 섞기
- 연령: 20~70대 다양하게
- 직업/상황: 실제 한국인 생활에 기반 (직장인, 주부, 자영업, 퇴직 등)

- 기존 페르소나와 겹치지 않게

- 대부분 ★5 (5점)

## ★ 금지/교체 표현

### 사용 금지 표현

| 금지 | 이유 | 대체 표현 |

- "양에 비해 가격이 좀.." 같은 불만은 **긍정 전환**하여 작성

- 4점 리뷰도 마무리는 긍정적으로 끝내기

## 주의사항

- 리뷰 번호는 기존 마지막 번호 + 1부터 시작
- 한 리뷰 안에서 상품 장점을 너무 많이 나열하지 않기 (1~2개면 충분)
- 광고 느낌 절대 금지. 실제 구매자가 직접 쓴 것처럼
- 기존 리뷰 전체를 먼저 읽고, 겹치는 포인트/페르소나/말투 파악 후 작성
