# 한려담원 흑염소 진액 - 리뷰 작성 가이드

## 공통 원칙

- "한려담원" 브랜드명 직접 언급: 전체의 40~50%만. 나머지는 "여기", "이 제품", "흑염소 진액" 등으로 대체
- 브랜드 런칭 초기 → "오래 먹었다 / 몇년째 먹고 있다" 표현 절대 금지
- "너무좋아요!", "최고입니다!" 같은 과장 표현 금지
- 한려담원 채널 = 건강 정보 전달 채널 (상품 홍보 X)
- 채널 → 건강 정보 신뢰 → 흑염소 진액도 판매한다는 걸 알게 됨 → 구매 흐름
- 핵심 타겟 증상: 수족냉증, 기력부족, 허약체질, 소음인, 임신준비, 임산부

## 타입별 정의 (10개 타입)

### 타입 1. 유튜브 채널 유입 (~20%)

한려담원 유튜브 건강 정보를 보다가 흑염소 진액 판매를 알게 되어 구매

키워드: 유튜브, 쇼츠, 구독, 건강 영상, 추천 영상

변형 세트:
- 쇼츠에서 건강 정보 보다가
- 유튜브 구독하고 있는데 흑염소 진액도 판매하시길래
- 유튜브 추천에 떠서 보기 시작했는데
- 건강 영상 찾아보다가 채널 발견
- 할머니 선물로 주문 (유튜브 경유)
- 임신 준비하면서 건강 영상 찾다가

### 타입 2. 인스타그램 유입 (~15%)

인스타에서 건강 정보 콘텐츠를 접하고 구매 (수족냉증/기력부족 등 본인 증상 관련)

키워드: 인스타, 릴스, 피드, 팔로우, 수족냉증 검색

변형 세트:
- 인스타 피드에서 건강 정보 게시물 보고
- 인스타 릴스에서 건강 정보 보다가
- 수족냉증 관련 계정 찾다가
- 수족냉증을 전문적으로 다루시는 채널이라 믿고

### 타입 3. 네이버 블로그 유입 (~10%)

수족냉증, 기력부족, 허약체질, 임신준비 등 본인 증상 검색 → 한려담원 블로그 발견 → 구매

키워드: 네이버, 블로그, 검색, 수족냉증, 소음인, 허약체질

변형 세트:
- 수족냉증 검색하다가 블로그 글 읽게 됨
- 소음인 건강관리 검색하다가
- 임신 준비하면서 체질 관리 검색
- 허약체질 관련 정보 찾다가

### 타입 4. 성분/원료 관심 구매 (~5%)

성분표 비교하거나 원료 구성이 깔끔해서 선택

키워드: 성분표, 원료, 첨가물, 비교, 국내산

변형 세트:
- 다른 제품들이랑 성분 비교해봤는데 여기가 깔끔
- 불필요한 첨가물 없는거 보고
- 국내산 원료에 성분표 깔끔한거 보고

### 타입 5. 재구매 (~5%)

본인이 먹어봤는데 괜찮아서 / 주변 추천으로 먹기 시작해서 다시 주문

키워드: 추가 주문, 재주문, 가족한테도, 비린맛 없다, 먹기 편하다

주의: "오래 먹었다" 금지. "먹어봤는데 괜찮아서 다시" 정도까지만

변형 세트:
- 먹어봤는데 비린맛 없고 먹기 편해서 다시
- 주변에서 추천받아 먹기 시작, 이번에 시댁에도
- 저도 먹어보고 괜찮아서 가족한테도
- 비린맛 걱정했는데 전혀 안 느껴져서

### 타입 6. 선물용 구매 (~12%)

부모님/시부모님/명절/생일/할머니/임신준비 언니-동생 등 선물 목적

키워드: 선물, 부모님, 시어머니, 명절, 생신, 할머니, 임신 준비

변형 세트:
- 부모님 건강 챙겨드리려고
- 시어머니 생신 선물로
- 명절 선물 준비하면서
- 장인어른 건강 선물로
- 임신 준비하는 언니/동생한테

### 타입 7. 가족 권유 구매 (~8%)

딸/아들/며느리가 추천하거나 대신 주문 (어르신 말투 다수)

키워드: 딸이, 아들이, 며느리가, 사줬읍니다, 주문해줬읍니다

변형 세트:
- 딸이 알아보더니 여기서 주문해줬읍니다
- 아들이 건강 챙기라고 주문해줬어요
- 며느리가 좋다고 사줬읍니다
- 어머니 드시라고 제가 주문했어요

### 타입 8. 건강 관리 목적 (~20%)

수족냉증/기력부족/소음인/허약체질 등 실제 증상으로 인해 직접 구매 (구체적인 고충 반영 필수)

키워드: 수족냉증, 기력부족, 소음인, 허약체질, 임신준비, 산후, 만성피로, 관절+냉증

변형 세트:
- 수족냉증으로 몇년째 고생
- 기력이 너무 없어서 일상생활이 힘들다
- 소음인으로 평생 살아옴
- 어릴때부터 허약한 체질
- 몸이 차서 임신 준비에 신경쓰고 있는데
- 출산 후 기력이 바닥
- 만성피로로 몇년째 고생
- 관절도 안좋고 손발도 차서

### 타입 9. 국내산 신뢰 구매 (~3%)

국내산 원료/제조라는 점에 신뢰

키워드: 국내산, 원산지, 국산 원료

변형 세트:
- 건강식품은 원산지가 중요한데 국내산이라 안심
- 국산 원료로 만든다고 해서 믿고
- 국내에서 제조한다니까 신뢰

### 타입 10. 지인 추천 구매 (~2%)

주변 지인이 알려줘서 구매

키워드: 동료, 친구, 이웃, 지인, 추천

변형 세트:
- 회사 동료가 비린맛 없고 먹기 편하다고 알려줘서
- 친구가 알려줘서
- 옆집 아주머니가 추천해줘서
- 지인이 선물 받았는데 좋다고 해서

## 중복 방지 전략

### 제목 중복 방지
1. 원본 제목 사용
2. 단어 치환 (구매합니다 → 사봤어요 / 주문합니다 → 주문해봤어요 등)
3. 어미 변환 (~합니다 → ~해요 / ~입니다 → ~이에요)
4. 접두사 추가 ("이번에", "처음으로", "드디어", "저도", "고민하다")
5. 조합 (치환 + 접두사)
6. 접미 부호 (~, !, .., ^^)

### 본문 중복 방지
1. 단어 치환 (주문했어요 → 주문해봤어요 / 찾아보다가 → 검색하다가 등)
2. 2~3개 치환 조합
3. closer 추가 ("감사합니다~", "잘 먹어보겠습니다." 등)
4. closer + 치환 조합

## 생성 스크립트

`scripts/generate-reviews.ts`

1. `completed-accounts.json` 로드
2. reviewCount > 0인 계정은 보호 (기존 리뷰 유지)
3. reviewCount === 0인 계정에 타입별 가중치에 따라 배분
4. 풀 내 리뷰를 셔플 후 순환 할당
5. 제목/본문 중복 방지 적용
6. JSON 저장

실행: `npx tsx scripts/generate-reviews.ts`

## 비린맛 관련 표현 (재구매/가족/지인 타입에서 사용)

재구매, 가족 권유, 지인 추천 타입에서는 "먹어봤다"는 경험이 있으므로:
- "비린맛도 없고 먹기 편해서"
- "비린내도 안 나고"
- "비린맛 걱정했는데 전혀 안 느껴져서"
- "먹기 편하고 비린맛 없다고 하시더라구요"

첫 구매 타입(유튜브/인스타/블로그/성분/건강/국내산)에서는 비린맛 언급 안 함 (아직 안 먹어봤으므로)
