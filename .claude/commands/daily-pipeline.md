# 한려담원 일일 파이프라인

계정 생성 → 상품 구매 → 구글 시트 기록을 한 번에 수행하는 자동화 파이프라인.

## 실행 방법

### 1. 새 계정 생성 + 구매 (기본)
```
/daily-pipeline 1      # 1개 계정 생성 → 구매 → 시트
/daily-pipeline 3      # 3개 계정 생성 → 구매 → 시트
```

### 2. 기존 미구매 계정 구매
```
/daily-pipeline jiyoung4433   # 특정 계정 구매
```

## 파이프라인 흐름

```
1. 계정 생성 (회원가입)
   - ID: 랜덤 (prefix + 숫자)
   - PW: 12Qwaszx!@ (고정)
   - 이름: 랜덤 한국 이름
   - 전화번호: 010-xxxx-xxxx (랜덤)
   - email: 랜덤

2. 상품 구매
   - 상품: 한려담원 흑염소진액 30포
   - 옵션1: "한려담원 흑염소진액"
   - 옵션2: "30포"
   - 결제: 무통장입금 (기업은행)
   - 배송지: 시트에 지정된 주소 사용 (고정)

3. 구글 시트 기록
   - 시트: "가구매 리뷰 계정" 탭
   - 컬럼: 수취인 | 참여ID | 배송지 | 구매일시
   - 시트 ID: 환경변수 GOOGLE_SHEET_ID
```

## 실행 전 필수 확인 사항

### 주소 중복 방지 (가장 중요!)
실행 전 **반드시** 구글 시트에서 기존 사용 주소를 조회하고, 겹치지 않는 주소만 배정해야 함.

```
1. 시트 "가구매 리뷰 계정" 탭에서 C열(배송지) 전체 읽기
2. ADDRESS_POOL에서 이미 사용된 주소 제외
3. 남은 주소 중에서 배정
```

- `run-daily-pipeline.ts`의 `generateAccount()` 호출 시 `ADDRESS_POOL`을 기본값으로 사용하되, 시트 기존 주소와 겹치지 않도록 필터링
- 이름도 기존 시트의 수취인과 겹치지 않도록 확인
- 사용자가 지역을 지정하면 (예: "경기도 서울 각각 하나씩") 해당 지역 주소로 배정

### 주소 풀 부족 시
ADDRESS_POOL 20개 중 사용 가능한 주소가 부족하면, 새 현실적 주소를 추가해야 함.

## 핵심 파일

| 파일 | 역할 |
|---|---|
| `run-daily-pipeline.ts` | 통합 파이프라인 스크립트 |
| `run-join-3.ts` | 회원가입 전용 |
| `run-purchase-and-sheet.ts` | 구매 + 시트 기록 |
| `accounts/completed-accounts.json` | 계정 DB |
| `.env` | Google 인증 + 시트 ID |

## 주소 규칙

- 한번 지정한 배송지는 **절대 변경 금지**
- 시트 배송지 = 실제 주문 배송지 (동일)
- 현실적인 주거 주소 사용 (아파트 동/호, 빌라 층 등)
- **이름 + 주소 모두 기존 시트 데이터와 겹치면 안 됨**
- 사용자가 지역을 지정하면 해당 지역 주소 우선 배정

## 주문 취소

- 구매자 계정에서 직접 취소 **불가** ("취소 신청이 불가능한 주문입니다" 에러)
- 관리자(사용자)가 직접 Cafe24 어드민에서 수동 취소해야 함
- 취소 필요 시 계정 ID + 주문번호를 사용자에게 전달

## 환경변수

```
GOOGLE_SERVICE_ACCOUNT_EMAIL=...
GOOGLE_PRIVATE_KEY=...
GOOGLE_SHEET_ID=...
HEADLESS=false
```

## 주의사항

- 비밀번호 조건: 대소문자/숫자/특수문자 2가지 이상, 10~16자
- 옵션 미선택 시 "필수 옵션을 선택해주세요" 에러
- 이전 주문 있으면 "새로입력" 탭 전환 필요
- 장바구니 confirm → dismiss (현재 수량만 구매)
- 카카오 주소 프레임: `postcode.map.kakao.com` (중첩 iframe)
- 카카오 주소 검색어는 도로명 핵심 부분만 (예: "월드컵로 120") — 너무 상세하면 검색 실패할 수 있음
